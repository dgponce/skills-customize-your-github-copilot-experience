# 📘 Assignment: Testing Python with pytest

## 🎯 Objective

Introduce automated testing using `pytest`, writing unit tests for functions and simple integration tests.

## 📝 Tasks

### 🛠️ Write unit tests

#### Description
Create a small module with functions and write `pytest` tests covering typical and edge cases.

#### Requirements

- Provide at least 4 unit tests covering different code paths.
- Use `pytest` assertions and fixtures where appropriate.

### 🛠️ Run tests and CI

#### Description
Demonstrate running tests locally and explain how to interpret failures.

#### Requirements

- Include a `requirements.txt` listing `pytest`.
- Provide commands to run tests: `pytest -q`.

**Skills practiced:** Test-driven thinking, writing unit tests, and using `pytest`.
