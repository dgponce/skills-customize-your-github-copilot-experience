# 📘 Assignment: SQLite Databases in Python

## 🎯 Objective

Teach students to use SQLite for local data storage: creating tables, inserting rows, querying, and updating records with the `sqlite3` module.

## 📝 Tasks

### 🛠️ Schema and CRUD operations

#### Description
Create a simple database schema (e.g., `notes` or `contacts`) and implement functions to create, read, update, and delete records.

#### Requirements

- Use `sqlite3` to create a database file and tables.
- Implement `create`, `read`, `update`, and `delete` functions.
- Demonstrate parameterized queries to prevent SQL injection.

### 🛠️ Export and import

#### Description
Add a script to export table data to CSV and import from CSV.

#### Requirements

- Provide `export_to_csv()` and `import_from_csv()` functions.

**Skills practiced:** SQL basics, local persistence, safe queries, and data interchange.
