# 📘 Assignment: Web Scraping with BeautifulSoup

## 🎯 Objective

Teach students how to retrieve and parse HTML content to extract data using `requests` and `BeautifulSoup`.

## 📝 Tasks

### 🛠️ Fetch and parse a webpage

#### Description
Use `requests` to download a sample page and `BeautifulSoup` to parse and extract specific elements (titles, links, table rows).

#### Requirements

- Use `requests` to fetch HTML content.
- Parse content with `BeautifulSoup` and extract structured data.
- Handle network errors and respect `robots.txt` in the description.

### 🛠️ Save extracted data

#### Description
Store extracted results as CSV or JSON.

#### Requirements

- Save output to `results.csv` or `results.json`.
- Provide example extraction code and sample output.

**Skills practiced:** HTTP requests, HTML parsing, data extraction, basic data persistence.
